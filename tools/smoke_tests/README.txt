Tests manuels / smoke tests Atlas V2

Ces scripts ne sont pas des tests pytest automatisés.
Ils doivent être lancés manuellement sous Windows.

Exemples :
    python tools\smoke_tests\test_atlas_service.py
    python tools\smoke_tests\test_restart_service.py
    python tools\smoke_tests\test_start_stop_service.py
    python tools\smoke_tests\test_storage.py
